# 2.0 商店截图版式

沿用 1.x 的蓝色云朵图标、蓝紫品牌色和明确的大标题；改用简洁的系统无衬线文字，提高中文和手机端可读性。没有绘制不存在的 Safari 浏览器栏、设备硬件框或新 UI。

颜色：品牌蓝 #287ED1，品牌紫 #6554BE，正文 #182B48，浅蓝底 #EAF1FB，白色 #FFFFFF。内容左对齐；Mac 使用左右两栏，iPhone/iPad 使用标题在上、真实界面在下的纵向结构。

每个平台三张：任务管理、批量导入、连接配置。中英文分别制作，共 18 张。默认场景关闭实验性玻璃。任务和文件示例在底部标明；文案不宣称下载速度、内置引擎或云端服务。

尺寸：Mac 2880×1800；iPhone 1206×2622；iPad 2064×2752。最终文件为 JPEG，移除 alpha。

## 原始 UI 输入

- 两种语言各提供 tasks、import、setup 三个当前 2.0 原始捕获。
- task/import 建议以 popup 真实宽度 440 CSS px、2× 像素密度捕获；避免包括浏览器开发者工具和个人内容。
- import 应展示实际多文件/种子选择面板，保留文件列表与按钮，不用旧界面占位。
- setup 建议捕获连接引导的主要面板（保留实际字段与连接测试按钮），而非将整个桌面页面缩小到手机尺寸。允许从原始截图裁取当前产品面板，不能改变控件内容。
- 实际 Safari 捕获优先；本地真实 HTML 的示例数据渲染可用于演示，但要在输入记录中标明数据来源。

`inputs.example.json` 是输入格式。只有 `verifiedCurrentUI=true` 的图才允许进入正式输出。默认 false，防止把旧截图当成新资源上传。
