Review Aria2 Helper

Aria2 Helper is a Safari web extension that controls an aria2-compatible JSON-RPC download engine. The containing app helps enable the extension; task management and settings are inside Safari. There is no app account, subscription, bundled engine, hosted download service or content catalogue. Leave “Sign-in required” unchecked.

The developer does not provide a public review engine. These steps use an engine you run in your review environment. Downloaded files are saved on the engine computer, not in the iPhone or iPad Files app.

1. Prepare an engine on the review Mac

Install aria2 from a source you trust. If Homebrew is already installed, brew install aria2 installs it. See the official aria2 project and aria2 command reference. Aria2 Helper does not install an engine.

For macOS review, run this in Terminal and keep it running:

REVIEW_RPC_SECRET="$(openssl rand -hex 24)"
printf 'RPC secret: %s\n' "$REVIEW_RPC_SECRET"
aria2c --no-conf=true --enable-rpc=true --rpc-listen-all=false \
  --rpc-listen-port=6800 --rpc-allow-origin-all=true \
  --rpc-secret="$REVIEW_RPC_SECRET" --max-download-limit=1K \
  --dir="$(mktemp -d /tmp/aria2helper-review.XXXXXX)"

This creates a temporary download directory, generates a secret, and listens only on the Mac itself. Keep the printed secret for the extension settings. The 1 KiB/s limit makes the small sample remain active long enough to try task controls. Stop the engine with Control-C after review.

2. Enable the Safari extension

  1. Mac: Open Aria2 Helper and open Safari extension settings. In Safari Settings → Extensions, enable Aria2 Helper and allow access to the website used for testing.
  2. iPhone or iPad: In Settings → Apps → Safari → Extensions, enable Aria2 Helper and allow access to the website used for testing. On older OS versions, Safari may appear directly in Settings.
  3. Open Safari, visit aria2.github.io, then open Aria2 Helper from the toolbar (Mac) or Safari’s extensions/page menu (iPhone/iPad). Use the settings control in the popup.

3. Connect from a Mac

In “Get started”, select aria2 and enter the following connection, then test and save:

4. Connect from an iPhone or iPad

Use the same review Mac as the engine computer and connect both devices to a trusted, isolated review LAN. The mobile device must be able to reach the Mac; guest Wi-Fi isolation, a firewall or a VPN can prevent this. 127.0.0.1 on the phone refers to the phone itself.

Stop the loopback engine (Control-C). For this LAN test only, run:

REVIEW_RPC_SECRET="$(openssl rand -hex 24)"
printf 'RPC secret: %s\n' "$REVIEW_RPC_SECRET"
aria2c --no-conf=true --enable-rpc=true --rpc-listen-all=true \
  --rpc-listen-port=6800 --rpc-allow-origin-all=true \
  --rpc-secret="$REVIEW_RPC_SECRET" --max-download-limit=1K \
  --dir="$(mktemp -d /tmp/aria2helper-review.XXXXXX)"

Determine the Mac’s LAN address in System Settings → Network → the active connection → Details. In Aria2 Helper settings on the phone/tablet, enter that LAN address, port 6800, and the newly printed secret. Test and save. The built-in “Get started” installation command refers to installing the engine on a Mac; the iPhone/iPad does not run that command. An existing connection can also be edited under Aria2 Settings.

This LAN command accepts connections on the Mac’s network interfaces. Use it only on your isolated review LAN, with the generated secret and narrowly permitted firewall access. Do not configure router port forwarding or expose it to the public Internet. Stop it after review. Use HTTPS for any engine connection across an untrusted network.

5. Exercise a small real download

  1. Open the Safari extension popup and use the add control to paste this official aria2 project README URL:
https://raw.githubusercontent.com/aria2/aria2/9e7273583f83e881e3ec067b523ba88724088d2f/README.rst
  1. Add the task. It is 22,434 bytes; with the sample limit it should remain active for roughly 22 seconds, subject to network overhead.
  2. Observe progress, pause and resume while active, then view the completed task. You can add it again to try removing an active task.
  3. On Mac only, “Reveal in Finder” is useful when the engine is running locally. Downloads are in the temporary directory created above. On iPhone/iPad, files remain on the engine Mac.

6. Test file imports and controls

  • aria2-readme.meta4 imports the same small official README using Metalink 4, with a size and SHA-256 checksum. Select it in the import file picker and submit to the connected engine.
  • selection-only.torrent is a generated, two-file, offline parsing fixture (137 bytes of described content). Import it, inspect/select the individual files, then cancel. It deliberately has no tracker, web seed or running seed and is not a download-completion test. No BitTorrent network access is needed to inspect the file list.
  • Automatic webpage link interception is off by default. Enable “Intercept download links” in Helper Settings if testing supported direct links. Cookie and referer forwarding can be disabled independently. Do not use private session cookies in the review sample.
  • Liquid Glass surfaces and popup background tint are experimental, off by default and unnecessary for the above steps.

Troubleshooting

  • Connection fails: Check host, port, secret, engine process and Safari website permissions. For mobile review, use the engine Mac’s reachable LAN address, not 127.0.0.1. Test network reachability and narrowly scoped firewall access.
  • HTTP versus HTTPS: Match the engine configuration. The supplied commands use HTTP only for loopback or an isolated trusted LAN.
  • Empty popup: Save the engine profile as the default connection, then reopen the popup.
  • The sample finishes too quickly: Ensure the engine was started with --max-download-limit=1K, then add it again.
  • Import completed but a file is not on the phone: The engine saves files on its computer. This is expected.
